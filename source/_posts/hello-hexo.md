欢迎来到我的技术博客。这是一篇示例文章，可以把它替换成自己的开发笔记、学习记录或项目总结。

写博客不需要一开始就写得很完整。从一个问题、一段代码、一次尝试开始，把过程记录下来。

<!-- more -->

## 写一篇新文章

在博客项目目录打开终端，运行：

```bash
npm run new -- "我的第一篇文章"
```

然后在 `source/_posts/` 中找到新建的 Markdown 文件。文件顶部的 `title` 是文章标题，`date` 是发布时间，`tags` 和 `categories` 分别是标签和分类；正文从第二个 `---` 下面开始。

## 用 Markdown 组织内容

用 `##` 写小标题，用 `-` 写列表，用一对反引号标记行内代码。

- 今天遇到了什么问题？
- 尝试过哪些解决办法？
- 最后发现了什么？

也可以放一小段代码：

```javascript
const message = '开始记录，也开始积累。';
console.log(message);
```

> 先让记录发生，再慢慢整理成自己的知识库。

## 在发布前预览

运行 `npm run dev`，再打开浏览器访问 `http://localhost:4000`。修改文章后，刷新页面查看效果。

## 接下来

把这篇示例文章改成自己的内容，在 `_config.yml` 中填写博客名称和作者。项目里的 `README.md` 记录了预览和发布的具体步骤。
